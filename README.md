# STM32 学习记录

记录个人学习 STM32 的实验工程、问题排查和学习笔记，分别使用 HAL 库与标准外设库进行练习。

## 目录说明

- `HAL/`：使用 STM32 HAL 库编写的工程。
- `Normal/`：使用 STM32 标准外设库编写的工程。

## 开发环境

- 开发板：正点原子探索者 V3
- 主控芯片：STM32F407ZGT6
- 开发工具：Keil uVision
- 下载器：ST-Link V2
- 下载接口：SWD

具体工程的编译器版本和配置，以该工程的设置为准。

## 使用方法

1. 进入对应实验的文件夹。
2. 使用 Keil 打开 `.uvprojx` 工程文件。
3. 编译工程，通过 ST-Link 下载到开发板。
4. 根据实验说明检查运行结果。

标准库模板中的 `project.uvoptx` 包含 ST-Link 下载配置，复制模板时需要保留。
